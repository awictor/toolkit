# Toolkit 🧰

A hub for a set of fast, private, **offline** calculators — pick the one you need and run your numbers with nothing leaving your device.

[![CI](https://github.com/awictor/toolkit/actions/workflows/ci.yml/badge.svg)](https://github.com/awictor/toolkit/actions/workflows/ci.yml)

**Live:** https://awictor.github.io/toolkit/

## The tools

| Tool | For | Live |
|---|---|---|
| **MarginMaster** | Amazon FBA sellers — true profit, margin, ROI, ACOS, FBA/storage fees, 9 marketplaces | https://awictor.github.io/margin-master/ |
| **Runway** | SaaS founders — LTV:CAC, payback, NRR, Rule of 40, burn multiple, cash runway | https://awictor.github.io/runway-calc/ |
| **RateRight** | Freelancers — the rate to hit your take-home goal after tax, expenses & unbillable time | https://awictor.github.io/rate-right/ |
| **Payoff** | Anyone with debt — snowball vs avalanche, debt-free date, total interest | https://awictor.github.io/payoff/ |

Every tool is a single offline `index.html`, zero dependencies, headless-tested, CI-green.
